# 视觉生成与独立输入

本文件负责整页视觉及局部图件的生成后端路由、参考图资格、独立输入、生成前门禁、三维图技术选择、有界并发、实际看图和返工。产物与接续机制见 runtime。

生产路径：`当前运行时 -> 当前宿主指定的生成后端 -> 本地候选 -> 实际视觉审核 -> approved-current`。

## 1. 宿主后端与独立调用

页面视觉生成/重生成按宿主固定路由，不另选或自动回退：

- **ChatGPT + CCM**：当前运行时调用 CPA；每页生成或返工均发起一个 fresh HTTP request。
- **Codex 原生运行时**：直接调用 Codex 内置 `image_gen.imagegen`；不调用 CPA，也不需要 CPA 端点或密钥。每页生成或返工都是新的独立工具调用。

两条路径共用 canonical、prompt、参考资格及候选审核规则。端点、模型发现、认证、配额与凭据属于当前运行时，不进入 canonical、prompt、README 或 Git。

**整页生成：一页每次生成/返工 = 一次独立调用；局部图件：每个图件每次生成/返工 = 一次独立调用。** 不在同一次请求夹带其他页或其他不相关图件。每次：

1. 重新读取当前页唯一 canonical、当前素材角色及对应参考图映射；**整页**按当前完整页面 prompt；**局部图件**从该页当前图件职责/素材、几何约束、处理目标形成自包含的完整局部 prompt，不照搬整页 prompt，也不建立第二套持久权威库。
2. `prompt` 参数逐字取此次**已经确定的完整输入**：整页使用唯一当前完整 prompt 文件原文，局部图件使用依据当前权威构造的完整图件 prompt 原文。不能临时口头追加或注入聊天历史风格/上一页要求；要修改生成指令，先改所属权威与本次完整输入。
3. 只附此次已查看且符合对应作用域的参考图；无参考就不传。整页生成禁止把旧生成的演示整页作为参考；局部图件参照下节的独立参考策略。不能依赖“同上一页”、上次失败提示或聊天记忆补齐输入。
4. 不主动继承任何前次请求的 generation/session/conversation 上下文或生成标识；返工仍用该页/图件的当前完整输入发起 fresh 新调用。

**ChatGPT + CCM / CPA**：使用独立新 HTTP 请求，仅发送当前页输入，不转发前次请求的生成/会话标识或历史图像。

**Codex 内置 ImgGen**：将本次完整 prompt 原文传入 `prompt`；仅在当前页/图件明确选有合格参考时以绝对路径填写 `referenced_image_paths`；禁止填写 `num_last_images_to_include`，避免自动从会话历史选取图片。全新文生图省略两种图片引用字段。**整页不得递归送回旧生成页；局部图件可在本图件范围按需附原图，不继承旧会话。**该规则保证模型控制的生成输入独立，不声称底层服务端完全无状态。

并发只能是多个独立调用，具体能力受当前宿主限制，不改变该约束。指定后端不可用时记录实际阻塞，不擅自换后端或修改科学内容。

## 2. 实际查看与证据边界

证据图和最终入选参考图必须实际查看，不能只凭文件名、目录、元数据、搜索片段或另一模型描述判断。预览/联系表可筛选候选，但最终每张仍须查看。

沿用来源索引记录足够溯源：来源、目标页、素材角色、是否已查看及当前资格。

- **实际项目/实践证据**：实际装置、实验、测量、数值结果、现场和事实记录，必须采用可追溯真实图或真实数据的忠实确定性重建，不能生成写实替身。
- **概念示意**：允许生成机制、结构、流程、物理关系或通用装置概念，但不能宣称是真实项目记录或测量。
- **工程/应用背景**：没有事实证明职责的通用场景可生成，包括写实场景；特定已命名设施/现场/事件身份承担事实主张时使用真实来源图。

标题、图注和正文不得把生成图写成实际证据。

## 3. 参考资格与格式

合格事实输入是已查看、可追溯且符合项目政策的真实源图，例如装置照片、真实对象/现场、源论文的定性事实图或仅用于定性物理背景的测量图。它们提供事实背景，不自动提供复制风格的许可。

若精确坐标、数值、图例、色标、不确定度、类别/曲线映射或数值标签承担证据职责，不交给生成模型重解释；从数据/代码重绘或保留真实原图，在 PPT 装配层直接放置。

**整页生成的参考禁令**：不得将旧生成的演示整页、AI 产出的旧整页、拒绝产物、Pipeline 图示、演示专用脚本图、答辩临时派生图或内部布局/关系校准图作为新的**整页生成**参考；它们可以内部查看诊断，用户明确覆盖时另按授权处理。可编辑重建目标也不自动取得整页生成参考资格。

**局部图件的参考选择**：Agent 根据实际改动幅度自行决定是否使用此图件的当前原图/对应裁图。原图的主体结构已经正确、仅需去字、接口上下小调或局部几何微调时，可带原图以保留正确部分；整体结构、几何关系或主要构图错误时，优先不带旧图从本图件权威重新画。连续修改出现漂移、错误固化或越改越乱时，停止把不合格输出继续当参考，返回正确源图或不用图重新生成。**这不是旧整页禁令的例外申请，而是局部图件的正常路由**；参考不得跨页串用，不允许将整页审核放大/裁切图未经图件身份核对自动变成生成参考。

独立风格/布局参考用于**整页**时仅在用户或项目明确选择、且不是当前演示的生成产物时使用；示例文件不是权威。局部图件原图参考只承担本图件结构/编辑职责，不自动变成全页风格权威。

参考必须是 PNG、JPG/JPEG 或 WebP 等图像。PDF 不直接作为图片参考：定位精确页面/图件 -> 转为图片 -> 实际查看 -> 核对裁切、清晰度与含义 -> 纳入当前页映射。

## 4. 输入与输出分工

canonical 是权威；当前 prompt 是派生指令；合格参考是该页输入；candidate 是待审核输出；approved-current 是当前已核查的成品。canonical 变化同轮覆盖同步唯一当前 prompt。

提交前核对：

- canonical 与**所选路径对应**的完整 prompt 一致、自包含：整页清除旧工况、标题、结论和布局措辞；局部图件只写该图的主体、要修改/保留的几何、符号、可移交 PPT 的文字与当前输出目标。
- 没有跨页隐含依赖、互相冲突的构图指令、伪造实际证据或定量图要求。
- 参考图当前、已查看、符合整页/局部图件对应规则；PDF 转换已检查，失效/禁用参考已移除。
- 图示表达科学关系，而非盲目继承旧生成图几何。
- 明确候选输出位置，不能含糊覆盖当前过审图。

## 5. 提示词完整性

整页 prompt 按页面职责写明标题、问题/结论、必须保留的事实/数字/公式/术语、证据角色、概念或背景图职责、阅读顺序、密度、版式约束、必要禁止项及需防止复发的渲染问题；不能只是 canonical 的过短摘要。局部图 prompt 则完整描述图件的结构/功能、保留与修改范围、需紧贴结构的内部标记、由 PPT 后加的外部标签及不应擅改的部分，不能把整页标题和所有正文强加到局部素材。

明确分开三个角色：

1. **必须显示**：准确的标题、正文、公式、数值、引用和标签。
2. **视觉职责**：关系、构图、阅读路径和设计约束，是施工指令，不是页面正文。
3. **不得显示/仅核查**：原始路径、网址、内部代号、溯源/审核说明及科学/施工约束；只有 canonical 明确指定可见引用时才显示对应内容。

不得将内部说明粘入可见正文。若反复泄漏成图，修正提示词结构后独立新调用返工，不修补生成图像素。

检查是否因过度压缩提示词而丢失必需的基准比较、关键推导、证据面板或解释层次；保证可读性，不以空白装饰替代论证。答辩专属密度与讲述规则见 research-defense。

## 6. 三维图与局部图技术选择

**针对 ImgGen 2.5 的项目经验**：复杂 3D 结构、精确工程几何和稳定透视的可靠性不足，尽量不让该模型从零绘制或大改这些图。优先保留可信来源图、使用已确认的 CAD/三维模型或专业工具确定性渲染，或改成更易准确说明的二维剖面、结构平面图及流程示意；自由注释可在 PPT 原生层做。只有不承担精确结构或定量证据职责、确能解释概念时才考虑生成式三维概念图，并严格验收几何与可理解性。该限制不泛化为所有 ImgGen 版本均不善三维，也不禁止使用真实三维图。

局部图重画先判断图内对象是否受几何耦合：压力表内 P、与设备轮廓紧贴的示意尺寸线/双箭头等可随 ImgGen 图形绘制；可自由移动的数值、解释文字和箭头原则上交给 PPT 原生对象。真正的尺寸值、科研数据坐标/刻度与精确几何关系须由可信原图、CAD 或数据/代码确定性绘制，不能让 ImgGen 猜值。具体去字与原生重建见 ppt-authoring。

## 7. 模型推进闭环

`选页 -> 生成前门禁 -> 独立生成调用 -> 本地候选 -> 实际看图 -> 通过或返工 -> approved-current`。

模型自行完成这个闭环，直到当前任务达标或实际阻塞，不要求逐次更新三类状态集合，也不把每张页的内部审核变成用户批准门禁。尚未委托的科学判断、重大设计选择或凭据配置需要用户信息时再交回必要问题；已有授权持续有效。

每次返工使用该页完整当前页面 prompt，或本次完整局部图件 prompt，与经重新核对的本次参考，不使用仅存在于聊天中的增量指令。旧失败理由作为复查重点，不自动判定新输出失败；局部图不因先前带图而必须继续带图。

## 8. 有界并发

宿主支持并发时可以保持少量独立调用在途，等待时准备下一合格页，结果返回即检查，通过即归入当前成品。允许跳号和乱序完成，不维护额外页面状态台账。

并发数、错峰和退避由项目、宿主与后端能力决定，不写通用固定数值。多个页面出现相同失败时停止扩队，先诊断是否为共同指令/风格缺陷；查明缺陷才修所属指令，单次差图不能推定 canonical 错误。

配额、限流、认证或后端阻塞按实际响应处理；已给出恢复时间时避免无意义重复探测。中断信息遵循 runtime，不新建失败分类数据库。

## 9. 成图审查与通过条件

每份新输出在实际审核前都是候选。对照当前 canonical、对应完整页面/图件 prompt、真实参考及其角色、要求的数值/公式/标签、信息层级与相邻页。先在完整画面上查主张、分组、阅读顺序，再在复杂/易漏区域局部放大查对齐、间距、换行、文字层级、对比度、图例/箭头落点和异常空白；局部查看不等于额外强制第二轮或另开独立 QA Agent。

检查工况/数据身份错误、伪造装置或结果、数值/公式/标签错误、证据太小、装饰挤占证据、旧页身份、密度/版式失败、无意义连接、不能解释页面问题的视觉、异常留白、字体替换、出框和数学乱码。**内容/证据正确和视觉品质合格分别判断**：即使能打开且无越界，视觉层级混乱、主要证据不可读、标记错位也要返工；反过来不能机械把适当高密度的科研页判为过载。普通三栏、公式框和箭头并非天然缺陷。

- **视觉阶段通过**：主构图、阅读路径、层级、核心证据和科学关系可靠；剩余局部错字、标签、公式文字、页码或箭头能在可编辑层可靠修复时，精确记录下游待修项。
- **生成返工**：结构、科学含义、证据或核心解释错误，不能安全留给下游。
- **交付检查**：待修项必须在编辑层修复并验证；纯位图交付不能延期到不存在的可编辑步骤。

局部图还须核对保留的主体几何、接口位置、压力表/尺寸符号、删字范围及是否让 PPT 标签能准确对齐。若继续带旧图使其结构漂移或错误累积，重画时改用原始可信图件或不带旧图；不需要反复请求用户决定参考方式。

approved-current 只表示该生成视觉经过实际审核、可复用，不表示无缺陷可编辑稿或用户最终认可。

## 10. 返工与产物保护

canonical/当前完整页面或图件 prompt 正确时只进行另一次独立生成调用；查明来源/指令缺陷时先修所属权威、同步完整输入，再生成。运行时授权、配额、超时、网络和后端故障不构成页面科学审核结论。

不得用代码擦除、拼贴、补丁、重绘像素或拼接权威生成原图来制造过审结果。进入可编辑施工后，在未改写原图的前提下构建原生对象或按用户要求原生裁切概念区域，属于下游施工，规则见 ppt-authoring。

输出留在当前项目运行时：新输出进 candidate，通过的进 approved-current，失败的留在当前成品视图外并按项目政策处理。不要凭文件存在判过审，不另建平行进度索引。

秘密保留在忽略的本地配置或安全运行时，永不进入 Git 或页面输入。
